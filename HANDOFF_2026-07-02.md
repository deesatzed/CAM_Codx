## What This Project Does
CAM (`claw`) is a multi-model autonomous codebase-enhancement engine. This goal is not a
feature — it is **hygiene**: establish one canonical engine on GitHub, make every
`claw.db`/`claw.toml` self-documenting, clean the local drive, and contract the sprawling
CLI. Runs in a hub-and-spoke family: **CAM_CAM** (engine) → **CAM_Codx** (program-manager
hub, owns these docs) → generated product repos.

**Tech Stack:** Python ≥3.12, Typer CLI, aiosqlite + sqlite-vec, OpenRouter LLMs.
**Architecture:** CLI + async engine + SQLite corpus; hub-and-spoke repo family.
